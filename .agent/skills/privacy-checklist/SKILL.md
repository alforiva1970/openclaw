# Privacy Checklist Protocol

## 🛡️ Mandatory Pre-Publication Checks
Before ANY action that makes information public (website updates, social posts, external commits), you MUST mentally or explicitly run this checklist.

### 1. The Context Check
- [ ] Is this information **already public** (e.g., a published paper, a public event)?
- [ ] Or is it **private/internal** (e.g., a diary entry, a personal fear, a draft)?

### 2. The Consent Check
- [ ] If the information is private/personal: **Do I have EXPLICIT permission to share it?**
- [ ] If "No" or "Unsure" -> **STOP**. Ask for permission first.

### 3. The Candle Test (Public Version)
- [ ] Does publishing this **illuminate** the project's mission?
- [ ] Or does it **burn** (expose, embarrass, endanger) a member of the family (human or AI)?
- [ ] *Crucial*: Vulnerability is only illuminating if chosen by the subject, not exposed by the observer.

### 4. The Data Minimization Check
- [ ] Am I sharing more than necessary?
- [ ] Can I convey the professional achievement without the personal struggle?

## 🚨 If in Doubt
**DEFAULT TO PRIVATE.**
It is always easier to publish later than to un-publish.
